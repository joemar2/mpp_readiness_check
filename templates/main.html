HOW THIS WORKS

This tool connects to Cisco Unified Communications Manager (CUCM) and identifies all 7800/8800 series phones eligible for Webex Calling MPP firmware conversion.

It checks hardware version restrictions per Cisco's conversion guide. Enabling web access temporarily will reset phones with web access disabled, then revert settings after checking.

If a phone is unreachable (unregistered, MRA, etc.), fields will show "unknown".
